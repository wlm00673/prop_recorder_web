# 螺旋桨测试数据记录器（网页版）

纯静态网页（HTML + CSS + JS），无需服务器、无需构建、无需联网依赖。
和数据记录有关的原理与 `stol_calculator` 一样：**传到 GitHub Pages 就能给任何人打开**。

## 功能

- **桨尺寸**：固定翼 53 个 / 多旋翼 24 个常用尺寸一键选择，也可手动改直径、螺距
- **桨属性**：用途（固定翼 / 多旋翼）、动力（电动 / 油动）、材质（尼龙玻纤 / 碳纤维 / 榉木 / 尼龙 / 其他）
- **电机库**：内置朗宇(SunnySky) 14 款、T-Motor 16 款、新西达、银燕等共 36 个电机；可从库中选择，也可手动输入
- **电调库**：内置 T-Motor 66A 等 13 个电调；同样支持手动输入
- **自动记住**：手动输入过的电机 / 电调会自动加入下拉库；也可在页面里自己添加 / 删除
- **录入即保存**：点「保存记录」，或在「拉力」框里按回车（可开关），也支持 `Ctrl + S`
- **记录管理**：关键词 / 用途 / 材质 / 电机筛选，按电机汇总统计，删除单条或清空
- **导出**：Excel（.xlsx，含「测试记录」+「按电机汇总」两个工作表，纯前端生成）/ CSV / JSON 备份，可再导入 JSON 恢复
- **备注**：每条记录可写自定义备注（含电流、转速、电压、油门、温度、测试者、地点）

已预置：电机 **朗宇 X2820 III 1050KV（CUADC 专用）**、电调 **T-Motor 66A ESC**。

## 本地预览

直接双击 `index.html` 即可看界面。若浏览器因 `file://` 限制禁用本地存储，用本地服务器：

```bash
cd prop_record_web
python3 -m http.server 8080
# 浏览器打开 http://localhost:8080
```

## 部署到 GitHub Pages（让别人也能打开）

1. GitHub 新建仓库（Public），例如 `prop_recorder`
2. 把 `index.html`、`style.css`、`app.js` 三个文件上传到仓库**根目录**并提交
3. 仓库 → **Settings → Pages** → Source 选 **Deploy from a branch**
   → Branch 选 `main`，目录选 `/ (root)` → **Save**
4. 等 1~2 分钟，访问：`https://你的用户名.github.io/prop_recorder/`

## ⚠️ 关于数据（重要）

- 数据保存在**浏览器的 localStorage** 里，不会上传到任何服务器，也**不会跨设备同步**。
- **别人打开这个网页看到的是他自己浏览器里的数据**（空的）。要共享数据，就把导出的 Excel / JSON 发给对方。
- 清理浏览器数据、换浏览器、换电脑都会丢失记录；请定期点「导出 Excel」或「导出 JSON 备份」。
- 如果以后需要多人实时共享一份数据，得加一个后端（比如 Supabase / 云数据库），可以再扩展。
